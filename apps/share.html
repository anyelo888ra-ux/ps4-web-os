Tu ID permanente de consola

Este ID se genera una sola vez por perfil en este navegador y se conserva localmente.

Compartir pantalla

Abre el panel emisor para compartir una pestaña o ventana. Para conectar otro dispositivo sin servidor ni base de datos, NEXUS.OS usa WebRTC con intercambio manual de códigos: oferta y respuesta. El enlace contiene el ID, pero no sustituye ese intercambio.

También funciona entre pestañas del mismo navegador mediante BroadcastChannel. La captura de pantalla requiere permiso del navegador y una conexión HTTPS. El control remoto se limita a NEXUS.OS; no controla el sistema operativo del dispositivo.

Compartir un juego

Los juegos publicados actualmente se guardan en localStorage y no aparecen automáticamente en otros dispositivos. En NEXUS Store puedes exportar un juego como archivo .nexusgame y compartir ese archivo; la otra persona podrá importarlo en su propia consola.

Comparte los enlaces y códigos de conexión solo con personas de confianza. Cualquier persona que tenga los datos de emparejamiento podría ver la pantalla compartida y enviar controles dentro de NEXUS.OS.
