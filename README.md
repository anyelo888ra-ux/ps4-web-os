# 🎮 PS4 Web OS Simulator

Un simulador de la interfaz de usuario (XMB) de PlayStation 4 construido con HTML5, CSS3 y JavaScript vanilla. Diseñado para ofrecer una experiencia fluida desde cualquier navegador, con soporte para teclado y controles por USB/Bluetooth.

## ✨ Características
- 🌊 **Fondo Dinámico:** Ondas animadas estilo PS4.
- 👤 **Selección de Usuarios:** Pantalla de inicio de sesión de usuario estilo PlayStation[cite: 11].
- 🎮 **Navegación XMB:** Menú horizontal con iconos de juegos y apps[cite: 10].
- 🕹️ **Soporte para Gamepad:** Navega la interfaz usando un control real (DualShock / Xbox / Genérico) mediante la *Gamepad API*.
- 🔊 **Efectos de Audio:** Sonidos nativos del sistema al cambiar de opción.

## 🚀 Probar en Vivo
Simplemente clona el repositorio y abre `index.html` en tu navegador, o entra al deploy automático.

```bash
git clone https://github.com/anyelo888ra-ux/ps4-web-os.git
cd ps4-web-os

```
